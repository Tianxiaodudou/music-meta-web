🎵 音乐数据刮削

总数统计（当前扫描到的全部歌曲）

还没有任何任务，按下面三步开始：
① 先在「应用中心 → 音乐数据刮削 → 设置 → 授权目录」把音乐目录（如 /vol2/1000/音频库）授权给本应用
② 到「配置」页确认音乐目录与数据源 → 保存配置
③ 点顶栏「① 扫描目录」→「② 开始刮削」
文件状态匹配结果得分已写入操作

自动写入队列（当前正在写入的歌曲始终在第一位）

导出后：下次全量扫描时，这些歌直接从本地缓存自动写入，不再请求服务器（更快、不风控）。

人工辅助队列（匹配值 < 阈值）

从每个文件的多条候选结果中选最匹配的一首。点「查看」可看该候选的全部字段（含封面与歌词），勾选/取消勾选决定选用时写入哪些字段；点「预览」可播放本地音频核对。

已人工处理（永久记忆，刮削时自动排除）

开启「真实写入模式」后人工处理过的歌曲会按文件哈希永久记住；之后开始刮削会跳过这些文件（即使总数统计里有它）。点「移除」可取消记忆。
