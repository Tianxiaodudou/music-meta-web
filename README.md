# 音乐数据刮削（Music Meta Scraper）

fnOS 原生应用，为本地音乐库批量补齐元数据的专业工具。支持 flac / mp3 / ogg / ape 等格式，自动从多个数据源检索并写入封面、歌手、年份、专辑、流派、唱片公司、语言、曲目号与内嵌歌词等标签。

## 功能介绍

- **智能识别匹配**：按「歌曲名-歌手」自动识别曲目，从多个数据源检索并写入完整元数据；也支持 AcoustID 音频指纹识别（需自行申请 Key）。
- **文件名多格式自适应**：文件名不必严格是「歌名-歌手」——自动识别 `_`、`–`、`—`、`｜` 等常见分隔符；识别结果不达标时还会自动尝试「歌手-歌名」反序补搜。
- **手动搜索兜底**：文件名格式特殊/识别不出来时，无需改文件名——在待人工队列点「✎ 手动搜索」，直接输入正确的歌名与歌手重新搜索即可。
- **自动化流程**：匹配值达到阈值即自动写入并永久记忆（按文件哈希），后续扫描自动跳过，避免重复请求；低于阈值的进入人工辅助队列，可逐条查看候选、对比试听与时长、勾选字段后合并写入。
- **多数据源插件化**：QQ 音乐 / 网易云 / 酷狗 / 酷我 / LRC Lib / TheAudioDB / iTunes 等数据源即插即用，内置全局限速与随机间隔防止风控，同曲目本地缓存零重复请求。
- **数据安全**：支持真实写入开关（默认仅学习预览）、目录级写保护与中文错误提示，任务与标签可随时复核、移回或删除。
